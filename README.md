One funny line of text, at most 140 characters — funny on its own, the laugh lands fast, and the angle is fresh. Three hand-written candidate jokes are scored against the judge's criteria and the winner is picked deterministically; the winning line is "I bought a self-help book, but it keeps asking me for advice."

## Run it

```sh
python3 main.py
```

This writes the winning line to `/output/entry.txt`.
